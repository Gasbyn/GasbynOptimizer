# Gasbyn Optimizer v2.0.B4

## Changes
- Embedded Apps Manager and Startup Manager inside the main window.
- Modern thin vertical and horizontal scrollbars.
- Startup check for changes to previously managed optimization settings.
- ON/OFF controls for HAGS and Fortnite Fullscreen Optimizations.
- Advanced mode indicates unsupported tweaks and locks them by default.
- Windows executable icon generated from Logo.png.

## Download
Use the `GasbynOptimizer-win-x64.zip` asset attached to the GitHub Release.
