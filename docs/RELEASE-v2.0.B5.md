# Gasbyn Optimizer v2.0.B5

## What's new
- One-click in-app update from the official GitHub Releases.
- Downloads are verified against the release asset's SHA-256 digest before installation.
- A separate updater waits for the app to close, backs up existing application files, replaces the published files, and attempts rollback if an update fails.
- After a successful update, Gasbyn Optimizer launches again automatically.

## Download
Download `GasbynOptimizer-win-x64.zip` from this release and extract the archive before running the application.
