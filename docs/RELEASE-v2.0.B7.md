# Gasbyn Optimizer v2.0.B7

## What's new
- The Benchmark page can automatically download the latest stable 64-bit PresentMon console executable directly from the official GameTechDev/PresentMon GitHub release.
- The download is limited to the expected official asset and verified against its published SHA-256 digest.
- Gasbyn Optimizer selects the downloaded PresentMon executable automatically and remembers its path.
- If PresentMon is missing when a benchmark starts, the app offers to download it automatically.
- Existing manual executable selection remains available.

PresentMon is stored under the current user's LocalAppData directory; no system-wide installation or registry change is required for the download.
