# Gasbyn Optimizer 2.0.0.86

## Co je nového
- Rozšířené čištění cache, TEMP a logů aplikací přes stávající tlačítko v Údržbě.
- Podpora dalších aplikací: Google Chrome, CapCut, Streamer.bot, Macro Deck, Streamlabs Desktop, Process Lasso a Visual Studio Code.
- Starší cache (7+ dní), TEMP (3+ dní), logy (14+ dní) a crash reporty (30+ dní).
- Běžící aplikace se přeskočí; zamčené a chráněné soubory zůstávají.
- Účty, cookies, hesla, nastavení, projekty, světy, hry, stažené soubory a zdrojová média se nemažou.

## Bezpečnost
- Nebylo přidáno nové tlačítko.
- Čištění vyžaduje potvrzení.
- Čištění probíhá pouze v konkrétních známých cache/log/temp umístěních.
- Odkazy na jiné složky a systémové soubory se přeskočí.
