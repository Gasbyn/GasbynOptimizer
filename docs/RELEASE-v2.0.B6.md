# Gasbyn Optimizer v2.0.B6

## What's changed
- Follow-up update for the in-app updater introduced in B5.
- Uses Windows PowerShell 5.1-compatible path handling when installing an update.
- Keeps package SHA-256 verification, staging, file backup, rollback attempt on errors, and automatic relaunch.
- The version is bumped so users can test the B5 → B6 in-app update flow.

## Updating
From B5, launch Gasbyn Optimizer and click **AKTUALIZOVAT** when B6 is detected.

This release packages the Windows PowerShell 5.1 compatibility fix for the in-app updater.
